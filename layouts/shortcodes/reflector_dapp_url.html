{{- /* Emits a Reflector-dapp deep link for one signature token, WITHOUT the `https://` scheme. All values are resolved from data, so addresses and variants stay in lockstep with data/unispring.yml and data/explorers.yml. The scheme is omitted so callers can write `https://` literally in the markdown — Hugo's render-link hook only adds `target="_blank"` when a link destination starts with literal `https://`. This mirrors the `escan` shortcode pattern in this codebase. Args: clone - clone key under unispring.reflector.clones (e.g. "1xUSDC") name - signature-token name to match within that clone's signatures list The dapp link is pinned to the default network's chain_id (not the explorer selector), because a signature token's liquidity lives on the one chain it was deployed to. */ -}} {{- $clone := index hugo.Data.unispring.reflector.clones (.Get "clone") -}} {{- $name := .Get "name" -}} {{- $sig := dict -}} {{- range $clone.signatures -}} {{- if eq .name $name -}}{{- $sig = . -}}{{- end -}} {{- end -}} {{- $cfg := hugo.Data.explorers -}} {{- $chain := (index $cfg.networks $cfg.default).chain_id -}} {{- printf "dapps.uniteum.one/reflector/#%s" (querify "chain" $chain "contract" $clone.address "name" $sig.name "variant" $sig.variant) -}}
